# docs/reviews/ — review reports

`REVIEW_<date>_<slug>.md`, one per deliberate review pass (whole-project, an aspect, a cross-project
crossover), `class: disposable`. **Local-only** (ADR-029): gitignored by pattern; this README is
tracked. A review lives until every finding has become a roadmap row, a KI or an ADR, then it
moves to `docs/archive/local/` (ADR-051 D2). The ledger of *when* each aspect was last reviewed —
and what each pass did not cover — is `.claude/REVIEWS.md`, not this folder.
